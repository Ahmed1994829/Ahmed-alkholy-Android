# Ahmed alkholy – Android WebView

هذا مشروع أندرويد يفتح موقع التطبيق الحالي داخل WebView:
https://medoaoft.fwh.is/

## بناء APK عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد أو إلى فرع `main` في مستودعك.
2. افتح تبويب Actions في GitHub.
3. اختر `Build Ahmed alkholy APK`.
4. اضغط `Run workflow` إذا لم يبدأ البناء تلقائياً.
5. بعد نجاح البناء افتح نتيجة التشغيل، ثم حمّل Artifact باسم `Ahmed-alkholy-debug-apk`.
6. فك ضغط الملف لتحصل على `app-debug.apk` وثبّته على هاتف Android.

## ملاحظات
- هذا إصدار تجريبي Debug وليس إصدار متجر موقّعًا بمفتاح نشر.
- تعديلات الموقع تظهر داخل التطبيق دون إعادة بناء APK.
- اختيار الملفات مدعوم عبر منتقي أندرويد. الوصول المباشر للكاميرا/الميكروفون من WebView يحتاج إعدادات أذونات إضافية واختبارًا على الجهاز.
- إشعارات الويب الفورية لا تصبح إشعارات أندرويد تلقائيًا بمجرد استخدام WebView؛ يلزم دمج Firebase Cloud Messaging أو خدمة إشعارات مناسبة.
- لا يحتوي المشروع على مفاتيح توقيع أو أسرار.
